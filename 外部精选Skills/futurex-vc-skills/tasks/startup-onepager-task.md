# Task: Startup One-Pager

## 使用 Skill

请先读取 `skills/startup-onepager.md`，并严格按照其中的步骤和输出格式执行。

## 输入材料

- BP 或公司介绍：`data/[project]/[source_files]`
- 访谈纪要或补充说明：`data/[project]/[notes]`
- 已有分析：`outputs/[project]/[existing_analysis]`

## 执行要求

1. 输出中文 FutureX 内部 One-Pager。
2. 控制篇幅，优先呈现影响投资判断的信息。
3. 公司快照中的每个关键字段必须标记来源类型或「待验证」。
4. 不把公司宣传语改写成确定事实。
5. 给出投资亮点、关键风险和建议下一步。

## 输出路径

请保存到：

```text
outputs/[project]/startup-onepager.md
```

## 保密检查

- One-Pager 如果包含真实公司敏感信息，不得提交仓库。
- 提交示例时使用虚构公司、脱敏字段或占位符。
- 不编造缺失字段。
