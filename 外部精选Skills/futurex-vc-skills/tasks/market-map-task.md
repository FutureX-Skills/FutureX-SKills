# Task: Market Map

## 使用 Skill

请先读取 `skills/market-map.md`，并严格按照其中的步骤和输出格式执行。

## 输入材料

- 赛道名称：`[market_name]`
- 地域与时间范围：`[region_and_time_range]`
- 已有公司名单或资料：`data/[market]/[source_files]`
- 用户关注问题：`[investment_theme_or_key_questions]`

## 执行要求

1. 先定义市场边界和不纳入范围。
2. 构建价值链和玩家分层。
3. 竞品信息必须标记来源类型和证据状态。
4. 不编造 TAM、CAGR、市场份额、融资金额、收入、客户数量或估值。
5. 输出 FutureX 可执行的 sourcing、访谈和研究动作。

## 输出路径

请保存到：

```text
outputs/[market]/market-map.md
```

## 保密检查

- 不提交真实内部项目名单或未公开项目信息。
- 使用脱敏公司或公开信息时标记来源。
- 无来源数据写「待验证」。
