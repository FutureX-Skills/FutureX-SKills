# Task: Memo to IC

## 使用 Skill

请先读取 `skills/memo-to-ic.md`，并严格按照其中的步骤和输出格式执行。

## 输入材料

- BP、One-Pager、市场图谱、Claim 核验、风险 memo：`outputs/[project]/[analysis_files]`
- 尽调底稿或访谈纪要：`data/[project]/[source_files]`
- IC 背景：`[meeting_date_decision_items_key_questions]`

## 执行要求

1. 先建立证据索引，区分已验证事实、公司自述、第三方报道、推测/判断和待验证。
2. 把投资建议放在前面，并说明 IC 需要决策的问题。
3. 投资假设必须配套支撑证据和反证信号。
4. 风险、估值、交易条款和融资信息如无可靠证据，必须写「待验证」。
5. 输出会后行动清单。

## 输出路径

请保存到：

```text
outputs/[project]/memo-to-ic.md
```

## 保密检查

- 不提交真实 IC memo、交易条款、财务底稿、客户名单或内部表决意见。
- 提交仓库前必须脱敏。
- 不编造投资金额、估值、退出假设或条款。
