# Task: Risk Memo

## 使用 Skill

请先读取 `skills/risk-memo.md`，并严格按照其中的步骤和输出格式执行。

## 输入材料

- 项目材料：`data/[project]/[source_files]`
- 已有初筛或 One-Pager：`outputs/[project]/[existing_analysis]`
- 用户指定重点风险：`[market_technology_team_financial_regulatory_financing_or_other]`

## 执行要求

1. 按风险类别系统识别，不只复述 BP。
2. 每个风险必须写清触发机制、影响、证据状态和核验/缓释动作。
3. 使用红 / 黄 / 绿风险分级。
4. 将公司自述的缓释方案标记为「公司自述」，不要视为已验证。
5. 明确哪些风险可能阻断投资。

## 输出路径

请保存到：

```text
outputs/[project]/risk-memo.md
```

## 保密检查

- 不泄露真实交易条款、财务底稿、客户名单或内部投资意见。
- 法律、税务、监管相关内容只作为投研风险提示。
- 缺少证据的信息必须标记为「待验证」。
