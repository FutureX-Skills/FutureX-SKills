# FutureX 公众号长文写作（futurex-writer）

将新闻、报告、访谈、语音转写或零散素材写成天际资本风格的公众号长文。

它覆盖选题判断、事实与敏感口径检查、文章结构、风格约束，以及交付前的四层自检。适用于天际资本公众号的 3000–5000 字长文，不用于短帖或标题摘要。

## 使用方法

把素材和希望落下的核心判断发给 Claude，例如：

```text
根据这份报告，写一篇天际资本风格的公众号文章。
```

涉及 portfolio 公司、敏感题材或内部材料时，请同时提供可公开的点名口径与边界。

## 一键安装

```bash
curl -fsSL "https://raw.githubusercontent.com/FutureX-Skills/FutureX-SKills/main/天际团队SKills库/futurex-writer/install.sh" | bash
```
