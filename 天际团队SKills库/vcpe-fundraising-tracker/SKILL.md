# VCPE 募资追踪器

追踪全球风险投资（VC）和私募股权（PE）募资动态，支持多数据源聚合。

## 功能

1. **最新募资新闻** — 获取全球最新 VC/PE 募资公告
2. **募资周报生成** — 汇总本周重大募资事件
3. **特定基金追踪** — 追踪指定机构或基金的募资进度
4. **地区/行业筛选** — 按地区或投资领域筛选募资信息

## 数据源

### 主要数据源

- **PitchBook** — 权威 VC/PE 数据平台（需订阅）
- **Preqin** — 另类资产数据（需订阅）
- **Crunchbase** — 部分免费数据
- **新闻源** — TechCrunch、VentureBeat、PE Hub、投中网、36 氪等

### RSS 订阅源

```
TechCrunch Funding: https://techcrunch.com/category/venture/funding/feed/
VentureBeat:        https://venturebeat.com/feed/
PE Hub:             https://www.pehub.com/feed/
```

## 使用方式

### 1. 获取最新募资新闻

```
用户: 最近有什么 VC 募资新闻？
→ 搜索最新 VC/PE 募资新闻并汇总
```

### 2. 生成募资周报

```
用户: 生成本周 VC 募资周报
→ 汇总本周重大募资事件，按地区/金额分类
```

### 3. 追踪特定机构

```
用户: 追踪红杉资本的募资情况
→ 搜索特定机构的最新募资动态
```

### 4. 地区/行业筛选

```
用户: 中国 PE 市场最近募资情况
→ 筛选中国地区的 PE 募资新闻
```

## 输出格式

### 募资事件条目

- **基金名称**：XXX Fund IV
- **管理机构**：ABC Capital
- **募资规模**：$500M（目标 $600M）
- **投资领域**：科技 / 医疗 / 消费
- **地区**：北美 / 欧洲 / 亚太
- **新闻来源**：[链接]
- **发布时间**：2024-XX-XX

## 执行方式

当用户触发本技能时：

1. **分析需求** — 确定用户需要：最新新闻 / 周报 / 特定机构 / 地区筛选
2. **选择数据源** — 根据需求选择搜索策略
3. **搜索信息** — 使用 web_search 或 web_fetch 获取最新数据
4. **整理输出** — 按标准格式整理募资信息
5. **生成报告** — 生成周报或摘要

## 注意事项

- 募资数据可能有延迟，标注数据来源和时间
- 区分"首次募集完成"和"最终募集完成"
- 关注币种单位（USD / CNY / EUR）
- 对大额募资事件优先展示
